# 음악 감상 퀴즈

유튜브 음원을 화면에 영상 없이 소리만 들려주고, 작곡가·시대와 작품명을 맞히는 감상 퀴즈. 곡 목록은 처음 전달받은 원본 목록 32곡(`js/songs.js`, 링크·시작 초는 Notion 「🎼 음악 감상 목록」과 대조). 재생은 공식 YouTube IFrame Player API를 화면 밖에 숨겨 쓰고(썸네일·제목 노출 없음), 진행 막대는 One UI 8.5 미디어 플레이어처럼 재생 중에 물결로 출렁인다. 전체 목록의 「듣기」도 외부 이동 없이 그 자리에서 재생되고, 집중 학습으로 고른 곡만 풀 수 있다.

## 실행

- 배포: `https://yyyyynny.github.io/playgrounddd/music-quiz/` (Pages 가 `main` 루트에서 배포)
- 로컬: 저장소 루트에서 `python3 -m http.server 8000` → `http://localhost:8000/music-quiz/`
- `file://`(파일 더블클릭)로 열지 않는다. 모듈 스크립트와 유튜브 플레이어가 동작하지 않는다.

## 채점

전체 일치만 정답. 공백 · 따옴표 · 가운뎃점 · 온점 · 쉼표 · 대소문자는 무시하고, `中` 자리는 '중' 으로 쓰거나(붙여 써도 됨) 생략해도 된다. `X(Y)` 는 X 대신 Y 로 써도 정답(예: 「르네상스 시대(조스캥 데프레)」 → 「조스캥 데프레」). 결과는 입력 순서대로 「작곡가 – 작품명」 한 줄로 보여 주고, 틀린 글자만 빨강으로 칠한다(`js/grade.js`).

## 곡 이미지

풀 때는 음반 자리에 문제 번호만 보이고, 제출하면 그 자리가 곡 이미지로 바뀐다(소리로 먼저 맞히고 정답과 함께 그림을 각인). 이미지는 `img/번호.webp` — 각 곡 유튜브 영상에서 고른 장면을 480×480 으로 잘라 낸 것이고, 영상이 없는 27번은 음소거 아이콘 `img/27.svg`. 장면을 바꾸려면 같은 이름의 파일만 교체한다. 파일이 없으면 번호 화면 그대로 둔다.

## 복습

한 라운드를 끝내면 틀린 곡만 다시 푸는 「틀린 N곡만 다시 풀기」 버튼이 나온다. 복습에서 또 틀린 곡은 다시 모아 전부 맞힐 때까지 반복할 수 있고, 「처음부터 다시 풀기」는 집중 학습 선택(기본 전체) 기준의 새 라운드다.

## 곡별 소리 크기

곡마다 소리 크기가 달라서 `js/songs.js` 의 곡마다 볼륨 `gain`(0~100)을 두었다. 2026-10-11 갤럭시에서 폰 볼륨을 고정하고 곡의 처음 10~20초가 편하게 들리는 정도로 맞춘 값에 전체 1칸(7.5)을 올린 것이며(63~100, 100 을 넘는 곡은 100 으로 잘림), 재생이 열릴 때 이 값으로 서서히 올라간다. **지금은 스위치 `GAIN_ON`(`songs.js`)이 꺼져 있어 모든 곡이 볼륨 100 으로 나오고, `gain` 값은 보관만 한다.** 켜려면 `GAIN_ON` 을 `true` 로 바꾼다. 다시 맞추려면 `gain` 숫자를 고치면 된다. 웹에서 볼륨을 못 바꾸는 기기(iPhone)에서는 적용되지 않고 기본 소리로 나온다.

## 움직임

Apple 디자인 원칙(`.claude/skills/apple-design`)을 따른다: 누르는 순간 반응, 시트는 아래에서 올라와 같은 길로 내려가고 머리를 끌어 닫을 수 있음(러버밴드 · 속도 예측), 반투명 재질, 진행 위치는 실시간으로 이어 그림, 재생·탐색·곡 전환·일시정지 때 소리를 서서히 키우고 줄여 끊김 소리를 없앰. 풀던 중 새로고침은 확인 창으로 막고, 모바일 당겨서 새로고침은 꺼 둠.
